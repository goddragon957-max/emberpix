## 브라우저 시나리오

1. 그림 도안 → 편집 → Undo/Redo → 자동저장 → 새로고침.
2. 보석 도안 → 한 칸 입력 → Undo/Redo → 보관함 → 재열기.
3. .emberpix 내보내기 → 격리된 새 세션 가져오기 → 데이터 비교.
4. 온라인 정상 사용 → 오프라인 재열기 → 온라인 복귀/업데이트.
5. 용량 초과·손상 파일·확인 취소 시 현재 작업/기존 저장 보존.

뷰포트: 360×800, 390×844, 844×390, 1280×800. 에뮬레이션을 실기기 통과로 쓰지 않는다.

## 협업·완료 정책

- App.jsx 및 갤러리 통합: 주 에이전트 단독 소유.
- 원본 도안 규격: 독립 담당; 시각 증거 전 도안 외형 수정 금지.
- 저장/프로젝트 회귀, 서비스워커 회귀: 별도 파일 소유권으로 병렬 진행.
- 각 슬라이스마다 테스트·빌드·진행 기록. 검증된 논리 단위만 한국어 Lore 커밋.
- 시각 verdict는 사용자 지시에 따라 `.omx/` 대신 이 폴더에 보관한다.
- 필수 시각 검증 미완료 시 푸시하지 않고 로컬 결과를 인계한다.
- 최대 24시간은 상한이다. 완료하면 조기 종료하고, 시간이 지나도 미완료를 완료로 바꾸지 않는다.
